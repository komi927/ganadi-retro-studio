# ガナディ ローポリスタジオ

[公開版で遊ぶ](https://komi927.github.io/ganadi-retro-studio/)

Three.jsで動く、ガナディとゴニャニのスタジオと広場です。HTML・CSS・JavaScriptをGitHub Pagesにそのまま公開しています。

## ローカルで起動

プロジェクトのフォルダで次を実行し、ブラウザで `http://127.0.0.1:8000/` を開きます。T3 Codeでは「ガナディ」プロジェクトの「ローカルで起動」を使えます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

JavaScriptのモジュールはHTTP経由で読み込みます。依存関係のインストールやビルドは不要です。

## 画面の操作

- 「👁」または H キーで操作UIを隠します。「UIを表示」、H、Esc のいずれかで戻せます。非表示中もドラッグで回転し、ピンチやホイールでズームできます。
- 上の「広場メニュー」から相方を呼んだり、ベンチやおやつ台へ移動したりできます。
- ゴンニョンイのベンチでは「のぼる」で、ガナディひとりでも相方と二匹でも乗れます。相方を呼んでいるときは二匹がベンチにそろうと選べます。「おりる」か移動操作で地面に戻れます。各操作は E キーでも選べます。
- 広場で相方の近くにいると「ほっぺを寄せる」を選べます。ガナディが近づくと、ゴニャニが一拍おいて横目で返します。
- 下の「表情」「かたち」「なでる」「写真」からキャラを操作できます。P キーでも写真を保存できます。

## ファイル構成

| 場所 | 内容 |
| --- | --- |
| `index.html`、`styles/` | 画面の構造とスタイル |
| `src/app.js` | スタジオと広場の状態、機能の接続 |
| `src/characters/` | キャラの形状、表情、ポーズ |
| `src/world/` | 広場の小物、ゴンニョンイ、移動と物理 |
| `src/graphics/` | PS1風の描画、背景とキャラの合成 |
| `src/input/`、`src/ui/` | キーボード・タッチ入力とメニュー |
| `src/export/` | 透過PNGの生成、GLBの書き出し、ファイル保存 |
| `vendor/` | Three.js r128、生成済みのTailwind CSSとライセンス |

公開元はこのリポジトリの `main` のルートです。JavaScriptとCSSは、GitHub PagesのプロジェクトURL配下で読み込めるように相対パスを使っています。

公開時に HTML・CSS・モジュールの組み合わせが変わる場合は、変更したファイルとその読み込み元の URL の `v` を更新します。ブラウザが新しいコードに古いキャッシュを混ぜるのを防げます。
